# Index

The router for this brain. Start here.

## Where things live
- `practices/` — how Claude should work (pre-loaded pack, refreshed by `/brain-update`)
- `projects/` — one file per project: stack, URLs, deploys
- `references/` — infra, services, auth, databases
- `meetings/` — Fathom calls turned into summaries and tasks
- `decisions/` — a log of what you decided and why
- `tasks.md` — the board your dashboard reads
- `staging/` — new notes waiting for review

## Getting started
1. Run `/brain-bootstrap` to map your repos into this brain.
2. Connect Fathom to auto-file your meetings (optional).
3. Just build. The brain grows on its own.
