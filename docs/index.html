The artifact

What actually lands on disk

Plain Markdown, Obsidian-compatible, in a private git repo. No database, no lock-in. Open it, edit it, grep it.

~/.claude/brain/
├─ CLAUDE.md # the router, loaded every session
├─ index.md # where everything lives
├─ practices/ # the shared pack, /brain-update refreshes it
├─ projects/ # one file per project: stack, urls, deploys
├─ references/ # infra, services, auth, databases
├─ meetings/ # Fathom calls → summaries + tasks
├─ decisions/ # log of what you decided and why
├─ tasks.md # the board the dashboard reads
└─ staging/ # new notes waiting for your review

Before you worry

What it will never do

Read-only audit

The seed pass reads and summarizes. It never edits your code, touches prod, or runs your programs.

Never stores secrets

It records where a key lives: the store or env var name, never the value itself. The brain holds no raw credentials.

Stays on your machine

Plain files in a private repo you control. Yours to read, edit, or delete. Nothing leaves without your git push.
